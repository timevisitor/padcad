# PadCAD 特征清单与边界（2026-11-04）

写给半年后接手的人：这份表是**代码行为的摘要**，不是设计愿望。
每一行「已知限制」都来自 `src/` 里的注释、报错文案或本文件末尾列出的实测（`probe-claims.mjs` 的输出见第六节）。
没验过的地方我标了「未验证」——请当成问号，不要当承诺。

> 状态（2026-11-04 实测）：24 个 op（另有 `pushface`、`surface_patch` 两个同义名）全部能在**脚本通道**（`runModelScript` / `__padcad.runScript` / 脚本面板）里跑通，且体积/包围盒能对解析值。
> **UI 入口在接线中**：`src/main.js` / `index.html` 里已经出现孔向导、布尔/分割/移动面/加厚、曲面四件的按钮与表单，
> 但那部分是与本文同期的并行开发，**交互路径（点面、选边、预览、失败提示）本次没有验收**。
> 下面所有参数、数值与限制都来自**脚本通道实测**，界面行为不要拿这份文档当依据。

## 一、通用约定（先看这一节，能少踩一半坑）

| 项 | 约定 |
|---|---|
| 长度单位 | **mm**（全部几何参数） |
| 角度单位 | **度**（`revolve.angle`、`move3d.rot`、`pattern.angle`、`hole.angle`、`fillet` 无角度） |
| 体积单位 | mm³（报告与 `expect.volume` 都是这个） |
| 方向 | `at` / `dir` / `normal` 都是世界坐标三元组；`dir`/`normal` 允许非单位向量（内部归一化），但**不能是零向量** |
| 参数表达式 | 字符串以 `$` 开头即表达式（`"$L*2-3"`）；`$PI`/`$E`/`$sqrt/$abs/$min/$max`；坐标里也可直接写 `"-($T+20)/2"` |
| 加减料 | 新 op 大多自带语义（`hole` 永远挖、`thicken` 永远是壁）；`primitive`/`helix` 用 `mode:"cut"` 切，默认加 |
| 校验 | 每步可写 `expect:{volume,bbox,faces,tol,bboxTol}`；体积默认相对容差 1e-3，包围盒 0.1mm，面数精确 |
| 严格模式 | 顶层 `strict` 默认 `true`：任一 expect 不过 → 中止且**不动当前模型**；`strict:false` 只标红继续 |
| 选择器 | 面 `{at,normal,type:"PLANE" 或 "CYLINDRE",uniqueTol}`；边 `{dir,closed,of,all,at}`；多候选**一律报错**，不猜 |

## 二、特征总表

### 2.1 起手与形体

| op 类型 | 参数（含单位） | 几何语义 | 已知限制 |
|---|---|---|---|
| `base` | 可选 `holeRadius`（mm，默认 6；必须 0<r<20） | 起始零件：60×40×8 板（XY 居中、z∈[0,8]）+ 中心通孔，体积 18295.2213 | 孔位固定在世界原点、外形固定，只适合当「从零开始」第一步；追加模式下它会把新零件叠在旧模型上（布尔 fuse），不是替换 |
| `primitive` | `shape`=box/cylinder/sphere/cone/torus；box `size=[宽x,深y,高z]`；cylinder `r,h`；sphere `r`；cone `r1,r2,h`；torus `R,r`；`at`、`dir`、`mode:add/cut` | 参数化基础形体，体积与解析公式误差 ≤4e-16 | **`box` 的 `at` 是底面中心、`cylinder` 的 `at` 是底面圆心**（不是中心）；`cone` 走 `BRepPrimAPI_MakeRevol`（wasm 里没有 `BRepPrimAPI_MakeCone`）；`torus` 要求 `r<R`，否则自交 |
| `helix` | `R` 中径半径、`wireR` 钢丝半径、`pitch` 螺距、`turns` 圈数（都可表达式）；`at`/`dir`/`clockwise`/`startAngle`；`mode` | 圆截面沿螺旋线扫掠成弹簧 | 必须 `wireR < R`；体积按 `π·wireR²·螺旋线长` 对账，相对误差 ~6e-7（扫掠离散，属预期）；不支持变螺距 |

### 2.2 草图驱动

| op 类型 | 参数（含单位） | 几何语义 | 已知限制 |
|---|---|---|---|
| `extrude` | `plane`（`{kind:"datum",name:"XY"/"XZ"/"YZ",origin,normal,xDir}` 或面引用）、`entities`、`depth`（mm，±）、`selected`、`constraints`、`grow`（mm，默认 0.002） | 草图轮廓沿基准面法向拉伸：`depth>0` fuse，`depth<0` cut | 第一步就 `depth<=0` 直接报「挖料需要一个已有的实体」；`grow` 是**沿法向多拉伸的余量**（避开共面退化），**不是轮廓外扩**——实测 20×20 轮廓 depth 10：默认 grow → 体积 4000.8、包围盒高 10.002；`grow: 0` → 4000.000 / 10。要精确对账就显式写 `grow: 0` |
| `revolve` | `plane` + `entities` + `angle`（度，默认 360）+ `axisX`（草图平面内的 2D 轴位置，mm） | 轮廓绕草图平面内的竖轴回转 | **别用 `sketch.revolve()`**（实测体积 0、包围盒扁平），必须走 `revolveSolid`；超出 0~360、轮廓跨轴等退化情形的报错文案未逐一验证 |
| `sweep` | `plane` + 两个 `entities`（第 1 个截面、第 2 个只用来描述长度）+ `length`（mm，可省） | 截面沿**草图法向**直扫 `length` | 只能沿法向直扫；任意 3D 路径**没接**（`MakePipeShell` 在 wasm 里能构造但本例体积读数 0）；`length` 省略时按第二轮廓推（rect 取最长边、circle 取直径、polyline 取首末点距） |
| `loft` | `plane` + ≥2 个 `entities` | ThruSections 蒙皮放样 | 截面必须来自**同一个**草图平面（界面上没有「不同平面选截面」的流程）；共面/零体积结果会被拒绝 |

### 2.3 实体特征

| op 类型 | 参数（含单位） | 几何语义 | 已知限制 |
|---|---|---|---|
| `pushpull` / `pushface` | `selector`（脚本）或 `faceRef`（点选）+ `dist`（mm，±） | 选中**平面**面沿法向扫成棱柱，再 fuse(d>0)/cut(d<0) | **只对平面面成立**：圆柱侧面这类曲面走这条路体积一点不变（`ops.js` 里明确写了），脚本里想改曲面请用 `surface_offset`；`abs(dist) < 1e-6` 时**静默返回原体**（不报错）；面选择器命中多个 → 报错 |
| `fillet` / `chamfer` | `radius`（mm）+ `selector`（脚本）或 `edgeRefs`（点选） | 对选中边做圆角/倒角 | 必须**全部**边成功，少一条整体报「圆角/倒角未能完整重建（成功 n/m 条），请减小尺寸或改变选择条件」——不返回半成品；允许的上限取决于相邻面几何，没有统一公式（未验证）；与曲面相邻的边稳定性未系统验证 |
| `shell` | `thickness`（mm）+ `selector`/`faceRef`（**开口面**） | 按选定面开口抽壳 | 壁厚必须小于零件上最小的圆角半径（实测：R2 圆角的 8mm 板 t=2 失败、t=1.5 与 t=1 成功）；失败时统一报「壁厚太大，或与已有的圆角/倒角冲突」，不猜具体半径 |
| `hole` | `kind`=through/blind/counterbore/countersink、`at`（**面上一点**）、`normal`（**朝外**法向）、`diameter`（mm）、`depth`（blind 用，mm）、`headDiameter`+`headDepth`（counterbore 用，mm）、`angle`（countersink 用，度，默认 90） | 在 `at` 处沿 `-normal` 挖：through 用长 `span=3×最大包围盒边+20` 的圆柱从面外穿入；blind 从面朝里挖 `depth`；counterbore 再挖一层 Ø`headDiameter`×`headDepth`；countersink 用锥（从 `headDiameter` 收到 `diameter`，深 `h=(hd/2−r)/tan(angle/2)`） | ①**孔位落在材料外不报错**（实测 `at=[100,0,8]` → 体积仍是 19200，白跑一步）；②`headDepth` 大于板厚也不报错，超出的部分落在材料外（实测 headDepth=9 / T=8 → 体积 18295.221，等于只有通孔）；③`normal` 必须是**朝外**法向，写反时刀具体从背面起刀，blind 会切错面；④不支持螺纹孔 |
| `split_plane` | `origin`（平面上一点，mm）、`normal`（法向，自动归一化）、`keep`=`positive`/`negative`（默认 positive） | 「保留侧半空间盒子 ∩ 实体」：盒子边长 `S=max(3×最大包围盒边, 20)` mm，从平面沿保留侧铺 | 没有用 `BRepAlgoAPI_Splitter`（避免两片谁正谁负的歧义），所以只保留一侧、结果是一个实体；**平面没真正切开时也不报错**（整块都落在保留侧 → 返回原体积，实测 19200），要判「确实切开了」得自己比体积；切不到材料才报错 |
| `combine` | `mode`=fuse/cut/common（别名 union/add、subtract/difference、intersect）+ `tool`（`{shape,尺寸,at,dir}`） | 与参数化工具体做并/差/交 | `tool` **只能是** box/cylinder/sphere/cone/torus，**不能**拿前面某一步的实体当刀（要那么做得换 `primitive`+`mode:cut` 或先导出再导入）；cut/common 无交集 → 报错；结果为空心 → 报错；体积方向异常（fuse 变小、cut 变大、common 超过任一方）→ 报错 |
| `offset_face` | `at`（面上一点，mm）、`normal`（面法向）、`distance`（mm，±） | 只对**平面**面：把面沿法向扫成棱柱再 fuse/cut，等价于把这张面精确平移 `distance` | **只支持平面面**，曲面直接报「曲面不能整体推拉，请改用其它特征」；`at` 必须离目标面 ≤0.5mm 且投影落在该面外框内；同位置有多块共面 → 报「这个位置有 N 个共面候选面」；`distance≈0` → 报错（不是静默跳过）；面法向需 >0.999 同向；带孔的面按**实际面面积**长料，不会把孔填死（回归已覆盖） |
| `thicken` | `thickness`（mm，必须 >0） | 闭合空腔：结果 = 实体 − 内缩 `t` 的实体（内缩体由 `shape.shell(t, 一个面都不选)` 给出） | **不支持选面开口**——开口抽壳请用 `shell`；`t×2` 必须小于零件最薄方向尺寸，否则提前报「两面内缩就会撞在一起」（实测 t=5 / 8mm 板）；内腔被吃掉 → 报错；与已有圆角/倒角冲突 → 报错；结果体积与「外形−内腔」对不上会报错（相对 1e-3） |

### 2.4 阵列 / 变换 / 导入

| op 类型 | 参数（含单位） | 几何语义 | 已知限制 |
|---|---|---|---|
| `pattern` | `source`（**步骤下标，0 起**）、`kind`=linear/circular、`count`、`spacing`（mm）+`direction` 或 `angle`（度，默认 360）+`axisPoint`/`axisDir`、`operation`=fuse/cut | 复制「源步骤**新增的那份材料**」，再与原实体布尔 | `count` 含原件；circular 在 `angle=360` 时步距 `360/count`，否则 `angle/(count−1)`；**源不含原件**，所以两次线性阵列是**累加**不是乘法；源被压制/删除 → 报错 |
| `mirror` | `source`、`plane`=XY/XZ/YZ、`offset`（mm，可省）、`operation` | 以标准基准面（可偏移）镜像源材料再 fuse/cut | 只支持三个标准基准面 + 偏移，**不能**以任意面/草图线做镜像面 |
| `move3d` | `dx`/`dy`/`dz`（mm）、`rot`（度）、`axis`=X/Y/Z、`pivot`=`"center"` 或 `[x,y,z]` | 整体平移/旋转，不改形状 | 只绕三个坐标轴；`pivot:"center"` 取包围盒中心；`rot` 为 0 时只平移 |
| `import` | `id`（运行时缓存键） | 把导入的 STEP 实体当起始体参与后续特征 | **STEP 不能进 JSON**：`id` 只是当前会话的句柄，重开工程必须重新导入；不要把它写进给用户长期保存的脚本 |

### 2.5 曲面（D 批）

| op 类型 | 参数（含单位） | 几何语义 | 已知限制 |
|---|---|---|---|
| `surface_offset` | `distance`（mm，非 0）、`face:{geomType,normal,at,index}`（对实体选面时）、`whole:true` | 实体：选一张面 → 厚度 abs(d) 的增料/减料体（内侧先缩 0.01mm 搭接）fuse/cut；片体/面：`BRepOffsetAPI_MakeOffsetShape` 整体偏置，**结果仍是片体**；`whole`：所有面一起偏置 | `whole:true` 是**近似**：圆柱 r20 h10 +2 → 21054.935，解析 π·22²·14 = 21287.43，**−1.09%**（端面棱边被圆弧吃掉）；选面路线的外表面尺寸仍精确（环外半径 22.00，0.01mm 只用于搭接）；片体偏置面积不变（20×20 仍 400），只改位置 |
| `surface_stitch` | `faces`（面选择器数组，可省=缝全部面）、`tolerance`（mm，默认 1e-4） | Sewing 缝合；自由边 0 → 转实体；没闭合但挨着 → 返回缝合片体；有真间隙 → 报错并给出实测间隙 | 至少 2 片；**间隙 > 10×tolerance 才报错**，间隙落在 tolerance~10×tolerance 之间会返回片体（这是容差语义，不是 bug，但会让「看起来缝上了」）；闭合壳朝向乱时用 `ShapeFix_Solid` 修 |
| `surface_fill` / `surface_patch` | `points`（`[[x,y]` 或 `[x,y,z]`，**≥3 点**）或传一个片体 + `boundary`=outer/inner | `BRepOffsetAPI_MakeFilling` 补一张面 | **产出是片体，不是实体**（实测该步体积 0、面数 1）；开口轮廓时 `IsDone()` 仍返回 true，只有面积变负——代码用「面积 >0」兜住；补出来的面不会自动缝到你已有的片体上，要实体还得 `surface_thicken` 或 `surface_stitch` |
| `surface_thicken` | `thickness`（mm，非 0）、`face`（片体有多个面时必须指定） | 片体：`MakeThickSolidBySimple` + 重新缝合 + `ShapeFix_Solid` 修朝向 → 实体；实体：选一张面加厚并 fuse/cut（与 `surface_offset` 共用增料路线） | `MakeThickSolidBySimple` 直接出来的壳**朝向是反的**（实测 20×20 片体 +3 → 体积 −1200），已由缝合+ShapeFix 修正，别绕开这两个函数；多面片体必须 `face` 指定（逐面加厚时侧壁会互相穿透）；片体太弯或厚度过大 → 报「还有 N 条自由边」 |

## 三、五条必须记住的「近似 / 静默通过」

这几条不是 bug，但写脚本的人不知道就会白干：

1. **`surface_offset` 的 `whole:true` 是近似路径**（−1.09%，实测值见上表）。要精确就对单个面用选面路线。
2. **`split_plane` 不检查「是否真的切开了」**。整块落在保留侧时它照样返回成功、体积不变。要断言切开，就写 `expect.volume = 原体积/2`。
3. **`hole` 不检查「孔是否在材料里」**，也不检查 `headDepth` 是否超过板厚。位置写错只会得到一个体积没变化的模型。
4. **`surface_fill` 产出片体**。片体没有体积（报告里是 0），拿它接 `thicken`（实体专用）会报「需要一个已有的实体」——要接 `surface_thicken`。
5. **`thicken` 是闭合空腔，不是抽壳**。要开口请用 `shell`；两者别混用（`thicken` 会拒绝「选面开口」这种参数，因为根本没有这个参数）。

## 四、会明确报错的情形（照抄自代码文案）

| 情形 | 报错（节选） |
|---|---|
| 参数表达式引用了不存在的参数 | `参数「X」没有定义（params 里只有：…；另有常量 $PI、$E）` |
| 表达式语法坏 | `表达式「…」第 N 个字符处看不懂（只能是数字、$参数、( ) + - * /）` |
| 选择器命中多个面/边 | `符合条件的面有 N 张，请用 face.at / face.normal / face.index 收窄到一个` |
| 选择器一个都没命中 | `找不到符合条件的面/棱边` |
| 第一步就是需要实体的特征 | `<特征名>需要一个已有的实体（第一步不能是它）` / `当前实体是空的，没有可加工的材料` |
| 分割切不到材料 | `这个位置切不到实体：平面过点 [x, y, z]、法向 …，保留 positive 侧没有材料` |
| 布尔无交集（cut/common） | `工具体与这个实体没有交集，切除不会去掉任何材料（请检查工具体的位置和尺寸）` |
| 布尔吃光材料 | `切除后没有剩余材料：工具体把实体整个吃掉了` |
| 移动面打在曲面 | `找不到要移动的面：[…] 附近没有法向 […] 的平面面（曲面不能整体推拉，请改用其它特征）` |
| 移动面点到多块共面 | `这个位置有 N 个共面候选面，无法唯一确定要移动哪个面（请换一个只在单块面内的点）` |
| 加厚壁厚过大 | `壁厚 5mm 太大：零件最薄方向只有 8.00mm，两面内缩就会撞在一起` |
| 抽壳壁厚与圆角冲突 | `抽壳失败：壁厚 2mm 太大，或与已有的圆角/倒角冲突。壁厚必须小于零件上最小的圆角半径…` |
| 补面点数不足 | `补面轮廓至少要 3 个点` |
| 补面轮廓不闭合 | `补面失败（N 点轮廓）：轮廓没有闭合，MakeFilling 拼不出一张面` |
| 缝合片数不足 | `缝合至少要两片，现在只有 N 片` |
| 缝合有真间隙 | `这两片不连续，缝不上（间隙 5.00 mm）；间隙要小于 0.0001 mm 才缝得上` |
| 多面片体加厚没指定面 | `这片片体有 N 个面，请用 face 指定要加厚的那一面（多面片体逐面加厚，侧面上的「壁」会互相穿透）` |
| 圆角/倒角没全成 | `圆角未能完整重建（成功 2/4 条），请减小尺寸或改变选择条件` |
| 孔类型/参数非法 | `孔类型只能是 through / blind / counterbore / countersink`；`沉头直径必须大于孔径`；`埋头角度必须在 1°~179° 之间` |
| 布尔模式非法 | `布尔模式只能是 fuse / cut / common（收到 "…"）` |
| 未知 op | `未知的操作类型：xxx` |

## 五、未验证 / 不确定（当成问号用）

- **UI 接线**：本文件写的 C/D 批特征，界面入口正在并行开发（`src/main.js`/`index.html` 已有按钮与表单），但交互路径（点面、选边、预览、失败提示）完全没有测过；界面会不会传对参数也未验证。
- **真机（小米 Pad 7 Ultra）**：这些特征没有在平板实测过性能与触控；`surface_*` 一类偏置在 wasm 里的耗时随模型规模的增长曲线没测（只测过 20×20/Ø40 的小件，几十到几百 ms）。
- **`extrude` 的 `grow`**：已实测默认 0.002 使 20×20×10 的拉伸体积变成 4000.8（+0.02%）、包围盒 10.002；但它与 `selected`/`constraints`（只拉伸选中轮廓、带约束的轮廓）的交互没测。
- **`sweep`/`loft` 的退化情形**：自交截面、截面数 ≠ 2、零面积轮廓的报错文案没逐条跑过。
- **`surface_stitch` 的 tolerance 窗口（tolerance…10×tolerance）**：只知道「不报错、返回片体」，实际几何是否可用来做后续布尔没测。
- **`fillet`/`chamfer` 的上限**：与相邻面几何相关，没有可复用的判据。
- **`hole` 与已有孔/槽相交**：布尔能过，但体积是否等于解析叠加值没验（沉头孔落在已有通孔上这类情况没测）。
- **`thicken` 对带内腔（先 shell 过）的零件**：内缩体如何与已有内腔相互作用没测。
