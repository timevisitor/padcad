## 6.0.2（versionCode 82）

v6 大改的**首个公开发布版**（6.0.0 / 6.0.1 只在本地迭代，未单独发 release）。

- **特征参数编辑成为可撤销动作**：改深度/圆角/孔直径等参数后，「撤销」恢复旧参数与旧实体，
  「重做」恢复新值；与新建特征、压制/删除、历史跳步使用同一套动作顺序。
- **预览不污染提交态**：预览与取消不写入撤销栈；重建失败回退到已提交画面；预览后输入原值确认会同步实际网格。
- **同面连续推拉合并**为一条历史记录，仍保持一个建模特征。
- 修复操作按钮禁用状态与历史栈深度慢一拍，以及清空选择后残留语境卡拦截后续选面的问题。
- 装配：多实体装配（示例件/本地件）、配合（同心/重合/距离/角度）、干涉检查、装配体保存与读取。
- 草图求解器 v6：LM + 数值雅可比，带自由度诊断与过约束提示；新增拖动/推断相关回归。
- 拾取走 `three-mesh-bvh`（新增运行时依赖，MIT），大模型选面更快；预览重建支持增量。
- 示例装配 JSON 打进 bundle（6.0.1 起）：APK 内 `fetch("samples/…")` 恒 404 的问题已消除。

验证口径：`npm test` 454 项 / 454 通过 / 0 失败 / 0 跳过（Node 22 + 真实 OCCT wasm，无浏览器）；
浏览器端验收与父会话独立复验记录见交接材料，本文档只记发布事实。

已知边界：没有参数表/变量与单位表达式；没有拓扑命名（复杂布尔后可能认不出来源，此时明确拒绝）；
面/边仍按解析几何 + 历史参数匹配。
